# Grille d'analyse d'un Reel

Adaptée de la grille « hook-analysis » du projet open source watchvideo (licence MIT, voir
`CREDITS.md` de ce skill). On **décrit** ce que fait la vidéo ; on ne la note pas.

Vocabulaire de travail : face au client, on dit **accroche dite** (hook parlé), **accroche
visuelle** (hook visuel), **temps** ou **rôle** (beat), **appel à l'action** (CTA).

Deux hooks, jamais un : le **hook parlé** (ce que l'oreille reçoit) et le **hook visuel** (ce que
l'œil reçoit). Ils diffèrent souvent, et cet écart est souvent la trouvaille la plus utile.

---

## Hook parlé

La première phrase complète prononcée, **verbatim**, avec son début. Si la vidéo démarre sans
parole : « aucun, silence jusqu'à 0:0X ».

| Type | Ce qu'il fait | Signe |
|---|---|---|
| **Contre-pied** | dit l'inverse de ce que le public croit | « Tout le monde te dit X. X est faux. » |
| **Précision** | ouvre sur un chiffre exact ou un objet précis | « 4 312 € en 11 jours » |
| **Compte à rebours** | met une horloge sur la récompense | « En 30 secondes, tu vas savoir… » |
| **Aveu** | avoue un échec ou un coût | « J'ai perdu six mois à cause de ça » |
| **Interpellation** | décrit la situation du spectateur | « Si tu postes tous les jours et que ça ne décolle pas… » |
| **Question** | ouvre une boucle qu'on veut fermer | « Pourquoi personne n'en parle ? » |
| **Rupture** | une phrase inattendue qui stoppe le défilement | « Stop. Pose ton téléphone. » |
| **Démonstration** | commente une action déjà en cours | « Regarde ce qui se passe quand je… » |
| **Autorité** | ouvre sur une légitimité ou une échelle | « Après 400 clients accompagnés… » |
| **Nouvelle** | annonce qu'un acteur vient de changer quelque chose | « Cette appli vient de tout changer. » |
| **Bénéfice immédiat** | promet un gain concret, souvent gratuit ou rapide | « Ce site gratuit fait X à ta place. » |
| **Aucun** | bonjour, raclement de gorge, logo | « Salut tout le monde, bienvenue… » |

« Aucun » est un vrai verdict : une ouverture faible est une trouvaille.

À noter : la citation, le type, le ressort en une ligne (quelle tension il ouvre), et si la
promesse est tenue (à quelle seconde) ou jamais.

## Hook visuel

Ce qu'on voit de 0 à environ 3 s, lu sur les images.

| Type | Ce que voit le spectateur |
|---|---|
| **Visage expressif** | un visage qui remplit le cadre, une émotion |
| **Texte accroche** | un texte plein écran qui porte la promesse |
| **Écran en action** | une capture d'écran déjà en mouvement |
| **Résultat d'abord** | un chiffre, un tableau de bord, un objet fini montré en premier |
| **Contraste** | deux états montés l'un contre l'autre (avant/après, chaos/calme) |
| **Face caméra simple** | la personne qui parle, cadre fixe, rien qui bouge |
| **Mouvement d'ouverture** | zoom brusque, panoramique rapide, raccord |
| **Objet montré** | un produit ou un objet tendu vers la caméra |
| **Faible** | logo, titre, cadre vide : rien pour accrocher l'œil |

À noter : le texte à l'écran à chaque image de 0 à 5 s, **verbatim** ; ce qui change entre 0, 1,
2, 3 et 5 s (coupes, mouvement, zoom, changement de sujet) ; la preuve montrée s'il y en a une ;
le cadre et le lieu (main levée ou pied, intérieur ou extérieur, bureau, rue).

---

## Alignement des deux hooks

| Verdict | Sens |
|---|---|
| **Alignés** | l'image montre ce que disent les mots, ils se renforcent |
| **L'image porte** | les mots sont faibles, c'est l'image qui arrête le pouce |
| **Les mots portent** | l'image est banale, c'est la phrase qui arrête le pouce |
| **En conflit** | ils se contredisent ou se concurrencent, l'attention se divise |
| **Tous deux faibles** | rien dans les 3 premières secondes ne mérite la quatrième |

## Format

Un format principal, plus des précisions.

| Format | Signature |
|---|---|
| **Face caméra** | une personne qui parle à la caméra |
| **Tutoriel écran** | capture d'écran commentée, étape par étape |
| **Voix sur images** | voix off sur des plans montés, personne à l'écran |
| **Liste** | des points numérotés (dits ou affichés) |
| **Histoire** | un seul récit avec un retournement |
| **Démo** | une chose utilisée ou fabriquée, du début à la fin |
| **Dialogue** | deux voix ou plus |
| **Pub** | une seule offre, le CTA comme colonne vertébrale |
| **Compilation** | des extraits de sources différentes |
| **Vlog** | une journée, structure lâche |

Précisions : sous-titres incrustés · coupes rapides (plus d'une toutes les 2 s) · coupes lentes ·
musique de fond · sans musique · beaucoup de texte à l'écran · visage en incrustation · split-screen.

---

## Structure en beats

Construite sur les vrais horaires de la transcription, jamais estimée.

```
0:00-0:03  Hook      « citation »                 [image : ce qu'on voit]
0:03-0:08  Relance   ce qui creuse la curiosité   [image : …]
0:08-0:30  Corps     le contenu, beat par beat    [image : …]
0:30-0:35  Preuve    la démo ou le résultat       [image : …]
0:35-fin   CTA       exactement ce qui est demandé [image : …]
```

Un beat qui n'existe pas est omis, pas inventé. Une vidéo sans CTA n'a pas de ligne CTA, et cette
absence vaut une phrase dans l'analyse.

---

## Pièges

| Piège | Pourquoi c'est faux |
|---|---|
| Paraphraser le hook | les mots exacts sont la matière ; une paraphrase est un autre hook |
| Ne rapporter qu'un hook | l'oreille et l'œil reçoivent deux ouvertures différentes |
| Noter au lieu de décrire | « super hook » n'apprend rien ; le type et son ressort, si |
| Deviner l'image depuis la transcription | une image non lue est « non lue » |
| Forcer une étiquette | une vidéo qui ne rentre dans aucune case reçoit une description |
| Inventer les vues | absentes sur Instagram : on le dit |
